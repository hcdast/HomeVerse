# 背景图片目录

## 📍 此目录用于存放 HomeVerse 的背景图片

### 需要的图片文件

请将以下两张背景图片放入此目录：

1. **`auth-bg.jpg`** - 登录/注册页面背景
   - 推荐尺寸: 1920x1080 或更高
   - 主题: 温馨家居场景
   - 文件大小: < 500KB

2. **`main-bg.jpg`** - 主界面背景  
   - 推荐尺寸: 1920x1080 或更高（建议2560x1440）
   - 主题: 现代简约空间或抽象渐变
   - 文件大小: < 800KB

### 📖 详细指南

完整的背景图片需求和设计建议请查看：
**`frontend/BACKGROUND_IMAGES_GUIDE.md`**

### ⚠️ 注意

- 如果没有提供图片，系统会自动使用渐变色背景
- 支持 JPG 和 WebP 格式
- 建议使用压缩工具优化图片大小
