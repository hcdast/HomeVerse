## 🚀 启动新功能

### 1. 重启服务

```bash
# 后端
cd backend
npm run start:dev

# 前端
cd frontend
npm run dev
```

### 2. 访问新功能

打开浏览器访问：
- http://localhost:3000/calendar - 家庭日历
- http://localhost:3000/finance - 财务记账
- http://localhost:3000/todos - 待办清单
- http://localhost:3000/recipes - 家庭食谱
- http://localhost:3000/health - 健康档案
- http://localhost:3000/wiki - 知识库
- http://localhost:3000/passwords - 密码管理
- http://localhost:3000/growth - 成长记录

### 3. 查看侧边栏

所有功能已按分类整理在左侧边栏中！
